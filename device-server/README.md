# device-server

On-device server started with `app_process` over adb (no root, no app install). It will be derived from
[scrcpy-server](https://github.com/Genymobile/scrcpy/tree/master/server) (Apache-2.0); see [NOTICE](../NOTICE).
Work starts in milestone M1. Design: [docs/ARCHITECTURE.md](../docs/ARCHITECTURE.md).
